不限行业：因子、水平、响应全部可改，适用于任何「多个工艺参数同时调、还要看交互作用」的实验——键合、电镀、注塑、蚀刻、化学合成都行。流程：定因子水平 → 生成随机运行序 → 填响应 → 效应 / Pareto / 交互作用 → 回归方程预测 → 多响应加权优化找窗口。数据只存本地浏览器，不上传。

1因子、水平与响应

因子 2–5 个（角点 2k 个），响应 1–4 个。水平间距按设备能力和历史工艺窗口定，不要超出安全区。每个响应单独定目标方向（越大越好 / 越小越好）。

2实验方案与结果

标准序是记账用的，实际运行必须按随机运行序做，否则设备漂移 / 环境变化会混进效应。黄色格子填实测响应，填完自动分析。也可以先导出 CSV 运行序表、在外面填好再导入。

3效应分析（Pareto）

效应 = 该项取 +1 时的响应均值 − 取 −1 时的均值（仅用角点计算）；回归系数 = 效应 / 2。条长按 |效应| 排序。中心点给出纯误差 SD：|效应| 大于约 2× 纯误差 SD 才值得认真对待（工程快速判据，正式结论看重复实验 / ANOVA）。

5预测与多响应优化

预测：拖动编码值，用回归方程算各响应的预测值，并换算成实际参数。优化：在 {−1, 0, +1}k 网格上按各响应归一化满意度加权搜索，列 Top 5。权重就是取舍：没有唯一的「最优」，只有说清取舍的最优。优化完必须做 3–5 批确认实验，别直接进量产。

⚠️ 模型只含主效应 + 二因子交互（线性 + 交互），不含平方项。若中心点均值与角点均值差得明显（见第 3 步曲率提示），说明有曲率，下一步应改用响应曲面（中心复合 / Box-Behnken）精调，别拿这个方程外推。
