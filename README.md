# DOE 全因子实验设计工具（2^k + 中心点）

一个单文件、纯前端的 DOE（实验设计）工具，不限行业：因子、水平、响应全部可改，适用于任何「多个工艺参数同时调、还要看交互作用」的实验——键合、电镀、注塑、蚀刻、合成都行。

**在线使用：https://xumingzhao0401-blip.github.io/doe-factorial-tool/**

打开即用，数据只存在本地浏览器（localStorage），不经过任何服务器。

## 功能

1. **定因子与响应**：因子 2–5 个（2 水平 + 中心点），响应 1–4 个，各自设名称、单位与目标方向（越大越好 / 越小越好）
2. **生成实验方案**：全因子角点 + 中心点，一键随机运行序，避免设备漂移和时间趋势污染效应
3. **效应分析**：主效应与二因子交互的效应估计（= 效应/2 得回归系数）、Pareto 排序、中心点纯误差与曲率检查
4. **交互作用图**：任选两个因子，看两条线平不平行——交互强不强一眼看清
5. **预测与优化**：编码值滑杆实时预测各响应；{−1, 0, +1} 网格加权搜索多响应兼顾窗口，权重可调
6. **CSV 导入导出**：运行序表可导出到线下填写，再按标准序导回

内置三个起点：键合参数案例（数据摘自公开文章）、注塑成型案例（构造的演示数据）、空白新建。

## 方法说明

- 效应 = 该项取 +1 的响应均值 − 取 −1 的响应均值，仅用角点计算；回归系数 = 效应 / 2，与 Minitab「Analyze Factorial Design」和 Excel 回归（编码列 + 乘积列）的口径一致
- 中心点用于估纯误差和曲率：|效应| 大于约 2× 纯误差 SD 是工程快速判据，正式结论看重复实验 / ANOVA
- 模型只含主效应 + 二因子交互，不含平方项；曲率明显时应转响应曲面（中心复合 / Box-Behnken），不要外推
- 优化结果取决于各响应的目标与权重，没有脱离取舍的「最优」；优化后必须做 3–5 批确认实验再进量产

## Excel 版

`工艺参数DOE实验设计工具包-复刻.xlsx` 是键合案例的 Excel 复刻件（5 个 Sheet：因子与水平 / 实验方案与结果 / 效应分析 / 响应优化对照 / 操作对照与核对），全部关键数字为公式联动，改响应即自动重算。`build_xlsx.py` 是它的生成脚本。

这个 Excel 版复刻自一篇公众号文章介绍的工具包（原文未提供公开下载）。复刻时按原文给出的 8 个角点数据重新计算，发现原文的效应值、回归方程中 AC/BC 系数、开裂主驱动归因与「分辨率 VIII」说法与其自家数据对不齐，复刻版一律按数据现算，差异逐条记录在 Excel 的 Sheet5 里。
